# RUST SIGNAL / РЖАВЫЙ СИГНАЛ

Браузерная игра с шестью эпизодами, энциклопедией, руководством и серверным рейтингом.

## Развёртывание

Поддерживаются несколько изолированных сценариев: обычный VPS с Nginx, осторожная замена одного сайта, установка только статических файлов в существующий веб-каталог, а также отдельный именованный HTTPS-сайт за Nginx stream/SNI.

Документация использует исключительно вымышленные домены из `example.com`, `example.net` и переменные-параметры. Реальные адреса, схемы маршрутизации, сертификаты, секреты и конфигурации конкретных серверов в репозитории не хранятся.

> Это самостоятельный исходный снимок проекта, без переноса истории другого репозитория. Полные команды появятся вместе с исходниками.
